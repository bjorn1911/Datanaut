### **Team Dynamic**: How did the teamwork go, roles and responsibility?
Everyone in the team shifted responsibility each week, if someone started as responsible for merging they would in the following week simply do another role.
What we did for this to work was to communicate with eachother and that way everyone knew what role they had for that day.

### **Communication**: How did make sure that everyone in your team understod the task and what to do?
When regarding this it was all about communication, if someone did not understand the task you had to ask.
And if we felt like someone in the group did not understand we simply ask them if they understod or if they wanted us to explain in another way.
  
### **Lessons learned**: What have you learned about working on projects in teams?
Communication is key. If you need help there is always help to get.

The few times when we had different opinions we made sure to listen to eachother and hear the difference in the soloutions.

During this project we had to remake it a few times since we did not have all the information on how SQL works to begin with.
So if we were to do this again we would have a better understanding on where and how to start and therefore be able to save lots of time.
